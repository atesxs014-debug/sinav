# Açık Lise Hazırlık

11 ders, 330 soru, 50 test (33 konu testi + 17 karma deneme), yanlış tekrarı, çıkmış soru PDF'leri için optik form.

- Sorular: `data/<ders>.json` — değiştirdikten sonra `node scripts/build-data.js` çalıştır.
- İlk kurulum: `npm run kur`
- Telefonda deneme: `npx expo start`
- APK + IPA: GitHub'a yükle → Actions → "APK ve IPA Derle" → Run workflow. IPA imzasızdır (Esign/Feather ile imzalanır).
